# Cursor Drift 需求与设计说明

- **文档版本**：0.4.2
- **状态**：已实现并推送 GitHub，36 项 Node 自动化验证通过；真实浏览器验收待完成
- **日期**：2026-10-15
- **项目类型**：Tampermonkey 浏览器用户脚本
- **目标仓库**：`https://github.com/madjatq/Cursor-Drift.git`（用户确认公开；本地 origin 已核对）

## 1. 背景与问题

普通网页缺少轻量、可随时关闭的鼠标视觉反馈。用户希望在浏览网页时看到跟随鼠标移动的粒子尾迹，并能在不修改网页内容的情况下切换不同视觉效果。

当前项目目录没有可复用的页面、组件、设计令牌、图片、字体或品牌规范，因此本项目采用一套独立、克制的悬浮面板样式作为最小风格基线：深色半透明面板、清晰的文本层级、适度圆角和阴影、较高但受控的层级值，以及可见的焦点状态。

## 2. 目标

1. 交付一个可直接安装到 Tampermonkey 的单文件用户脚本。
2. 在鼠标移动时绘制流畅的粒子尾迹，并提供多种差异明显的预设。
3. 通过网页右上角悬浮设置面板即时切换效果和调整通用参数。
4. 默认覆盖所有普通 `http/https` 网页，同时自动排除浏览器内部页面。
5. 在输入、文本选择、页面不可见和设备性能不足时减少干扰与资源消耗。
6. 提供安装、使用、兼容性和隐私说明，并将完整项目上传到公开 GitHub 仓库 `cursor-drift`。

## 3. 非目标与反目标

### 非目标

- 不修改网页正文、链接、表单数据或业务逻辑。
- 不提供在线账户、云端同步、统计分析或远程配置。
- 不要求外部 CDN、第三方运行时或联网服务才能显示效果。
- 不把项目做成复杂的粒子编辑器或动画制作工具。
- 第一版不专门适配移动端触摸手势。

### 反目标

- 粒子遮挡按钮、输入内容或主要阅读区域。
- 页面切换、滚动或动画导致明显卡顿。
- 设置面板默认展开并长期占据视线。
- 用户关闭后仍在后台持续生成大量粒子。

## 4. 用户与场景

主要用户是希望为日常网页浏览增加轻量视觉反馈的桌面浏览器用户。典型流程如下：

1. 用户在支持 Tampermonkey 的现代桌面浏览器中安装脚本。
2. 打开普通网页后，鼠标移动产生默认粒子效果。
3. 用户点击右上角的悬浮按钮，打开设置面板。
4. 用户切换预设或修改参数，画面即时更新，不需要刷新页面。
5. 用户离开输入框、文本选择或页面后，效果根据当前状态自动暂停或降级。
6. 用户的设置保存在浏览器本地，下次打开网页继续生效。

## 5. 已确认事项、推断与设计决策

### 用户已确认

- 项目需要一个英文项目名，暂定为 **Cursor Drift**。
- 运行方式为 Tampermonkey 用户脚本。
- 鼠标移动时显示粒子效果。
- 粒子效果需要多种预设，并可通过设置更换。
- 设置入口为网页右上角悬浮面板。
- 第一版预设和参数由 Codex 按最佳实践设计。
- 默认覆盖所有普通网页，并提供总开关。
- 输入框聚焦、选择文本或页面不可见时暂停。
- 低性能设备自动降低粒子密度。
- GitHub 仓库名为 `cursor-drift`，公开。
- GitHub 上的公开仓库已创建；Git 操作环境已在用户电脑的 Git Bash 中配置完成。本地 origin 为 `https://github.com/madjatq/Cursor-Drift.git`；推送结果需在交付阶段验证。
- 设置使用 Tampermonkey 的 `GM_getValue/GM_setValue` 全局保存，同一浏览器不同普通网站读取同一份设置；不收集网页内容、鼠标轨迹或远程数据。
- 设置面板使用中文，README 使用中英双语。
- 遵循 `prefers-reduced-motion: reduce`：降低粒子密度与寿命，保留手动开关和参数控制。

### 基于资料推断

- “普通网页”按 `http` 和 `https` 页面理解；浏览器内部页面通常无法被 Tampermonkey 注入，仍需在脚本匹配规则和运行时检查中双重防护。
- 主要使用场景是桌面鼠标，第一版可将触摸设备视为不支持或降级场景。

### Codex 建议的默认决策

- 使用单个全屏透明 `canvas` 作为渲染层，避免向网页插入大量粒子 DOM 节点。
- 使用 `requestAnimationFrame` 驱动动画，并限制粒子总量；默认上限建议为 300，设备检测后动态调整。
- 提供 4 个预设：`Stardust`（细小星尘）、`Neon Pulse`（霓虹光点）、`Soft Bloom`（柔和彩点）、`Comet Trail`（方向性拖尾）。预设只改变视觉参数，通用设置仍可覆盖。
- 通用设置建议包括：启用/暂停、当前预设、颜色模式或自定义颜色、粒子大小、密度、拖尾寿命、移动速度、透明度。
- 设置面板默认收起，只显示一个可识别的悬浮按钮；面板采用深色半透明、圆角和轻阴影样式，具备键盘焦点状态和较高层级值。
- 当输入框、文本域、可编辑元素或内容可编辑区域聚焦时暂停；检测到文本选择时暂停；页面进入后台或不可见时暂停；帧率持续偏低时自动减少密度并在恢复后逐步回升。
- 首选支持 Tampermonkey 的现代 Chromium 系浏览器和 Firefox；不承诺浏览器内部页面、受严格 CSP 或特殊沙箱页面的显示效果。
- 公开仓库建议使用 MIT License，便于用户安装、修改和分享。

### 待用户确认

- 需求确认已完成，无待确认的实现范围；浏览器验收受当前环境限制而未完成，属于验证阻塞，详见 [验证记录](../../verification.md)。

## 6. 功能需求

### 6.1 粒子渲染

- 鼠标移动后生成粒子，粒子位置、速度、透明度和寿命随时间更新。
- 粒子应自然衰减，不留下永久痕迹。
- 粒子渲染层不应改变网页布局，不应拦截鼠标点击或键盘事件。
- 页面尺寸变化、缩放和高 DPI 屏幕应保持合理的视觉比例。
- 鼠标快速移动时应限制生成速率和总量，避免粒子数量无限增长。

### 6.2 预设与参数

- 设置面板提供 4 个预设并显示当前选择。
- 切换预设立即影响新生成和现有粒子；不要求刷新页面。
- 通用参数修改应立即生效，并提供适合非技术用户理解的标签。
- 参数必须有安全范围、默认值和必要的可访问文本。

### 6.3 设置面板

- 面板固定在网页右上角，默认收起。
- 必须提供总开关、预设选择和通用参数控件。
- 面板打开、关闭和参数切换不应触发页面跳转或刷新。
- 面板应尽量避免遮挡网页内容；在窄视口中需要限制宽度并保持可操作。
- 面板及按钮应支持键盘聚焦，文本和控件具有可读对比度。
- 设置面板自身不产生粒子，或在面板交互期间避免造成额外视觉干扰。
- 面板可以保持展开；鼠标离开面板后即可预览，面板控件保留焦点不会阻止页面外侧的粒子。实际页面编辑焦点仍触发暂停。

### 6.4 自动暂停与性能降级

- 总开关关闭时停止生成和更新粒子，并清理渲染资源。
- 输入框、文本域、可编辑元素聚焦时暂停。
- 用户存在文本选择时暂停，选择结束后恢复。
- 页面不可见或进入后台时暂停动画循环，恢复可见后继续。
- 运行时根据帧率或设备能力降低密度；降级过程应平滑，不应频繁跳变。

### 6.5 全局设置

- 设置通过 Tampermonkey 的 `GM_getValue/GM_setValue` 在同一浏览器的不同网站间全局持久化保存。
- 若运行环境不提供 GM 存储 API，则回退到当前网站的 `localStorage` 或当前会话内存，并在 README 中说明限制。
- 读取损坏或版本不匹配的设置时回退到安全默认值。
- 不向网络发送设置或页面信息。

### 6.6 语言与减少动态效果偏好

- 设置面板控件、状态提示和可访问性文本使用中文。
- README 同时提供中文和英文的安装、使用、兼容性、隐私和故障排查说明。
- 检测到 `prefers-reduced-motion: reduce` 时，默认使用较低粒子密度和较短寿命；用户仍可手动打开总开关并调整参数。

## 7. 输入、输出与异常边界

### 输入

- 鼠标移动坐标和时间间隔。
- 页面可见性、窗口尺寸、设备像素比和粗略性能指标。
- 用户在面板中选择的预设、开关和参数。

### 输出

- 覆盖在页面之上的透明粒子画布。
- 右上角悬浮设置面板。
- 浏览器本地保存的设置数据。

### 异常与边界

- 无法创建 `canvas` 或获取绘图上下文时，脚本应安静退出并避免影响页面。
- 不支持 GM 存储 API 和 `localStorage` 时仍可运行，但设置只在当前页面会话有效。
- 页面已有同类全屏画布或极端层级样式时，脚本应尽量降低层级冲突；无法兼容时允许用户通过总开关关闭。
- 视口改变时调整画布，单页应用路由切换沿用同一实例，不重复创建面板或画布。
- `pagehide` 的 `persisted` 为真时暂停，`pageshow` 时恢复并重算尺寸与暂停条件；最终非缓存 `pagehide` 清除动画、监听器、画布和面板。

## 8. 权限、安全与隐私

- 仅申请实现所需的页面运行权限，不使用网络请求权限。
- 不读取或保存网页文本、表单内容、Cookie、令牌或账号信息。
- 不向第三方发送数据，不包含远程脚本注入。
- 所有用户输入参数均需限制范围，避免通过设置面板插入 HTML 或脚本。

## 9. 兼容性与性能目标

- 目标环境：Tampermonkey + 现代 Chromium 系浏览器和 Firefox 桌面版。
- 匹配普通 `http/https` 页面，浏览器内部页面不作为支持目标。
- 默认状态下不应持续占用明显 CPU；页面不可见时停止动画循环。
- 在中等性能设备上，默认效果应尽量接近 60 FPS；性能不足时优先减少粒子数量和生成频率。
- 脚本应避免引入外部依赖，以便单文件安装和离线运行。

## 10. 交付物与验收标准

### 交付物

- 可安装的 `cursor-drift.user.js`。
- `README.md`：安装、功能、设置、兼容性、隐私和故障排查说明。
- `LICENSE`：建议采用 MIT License。
- 本设计文档及后续实现计划。
- 公开 GitHub 仓库 `cursor-drift`，包含 Git 提交历史。

### 验收标准

1. 在 Tampermonkey 中安装脚本后，打开普通网页即可看到默认粒子尾迹。
2. 右上角面板可以打开、关闭，且不会改变网页布局或拦截页面点击。
3. 4 个预设均可即时切换并呈现可辨识的视觉差异。
4. 总开关和通用参数即时生效，刷新当前页面或打开另一个普通网站后设置仍能恢复。
5. 输入框聚焦、文本选择和页面不可见时粒子暂停；恢复条件后按规则恢复。
6. 模拟低性能或高粒子压力时，粒子密度会自动降低，页面仍可正常操作。
7. 浏览器内部页面和不支持脚本注入的页面不会被破坏或报出影响用户的错误。
8. 代码检查、功能测试和必要的浏览器手动验证通过，README 能让新用户独立完成安装。
9. Git 历史清晰，项目最终推送到公开的 `cursor-drift` GitHub 仓库。
