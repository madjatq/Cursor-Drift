## 发布与实施决策

2026-10-15 已推送到 [GitHub 仓库](https://github.com/madjatq/Cursor-Drift) 的 `main` 分支。推送前重新运行全部 36 项测试、语法和差异检查；推送后确认远程提交、工作区状态、安装链接 HTTP 200 及脚本内容一致。各阶段审阅和最终整体验证无遗留阻塞代码问题，最后一项暂停清理优化已经复审。

实施时采用以下决策，需求未因此扩大：

1. 空项目初始化后在 `feature/cursor-drift` 分支开发，交付时改名 `main`；没有创建额外 worktree。若需要并行开发，可补建 worktree，不影响本次代码。
2. 计划补全 Node 测试命令与 Tampermonkey 匹配和权限字段，使安装与验证可重复；若运行环境要求变化，需要同步修改元数据及测试。
3. Windows 使用 `npm.cmd test`，运行与 `npm test` 相同的脚本；无需改变 PowerShell 执行策略，无产品行为影响。
4. resize/SPA 保留实例，BFCache 暂停恢复，最终 pagehide 清理；避免调整窗口后特效失效。真实浏览器生命周期差异仍待人工验证。
5. 设置面板展开时允许面板外实时预览，只在面板指针交互时暂停；会在调参后移动鼠标时显示动效，仍可随时用总开关关闭。
